## Purpose
This repository documents my personal IT and cybersecurity home lab projects, with a focus on cloud security, identity protection, threat detection and security automation.

I originally started this journal to record what I was learning as I explored Microsoft Azure and Microsoft 365. Since then, it's developed into a collection of practical security projects where I can experiment with new technologies, troubleshoot problems and apply concepts I've encountered in my professional work.

My aim is to document not just what I've built, but why I've built it, how it works and what I've learned along the way.

---

## Skills Demonstrated
- **Cloud & identity Security:** Microsoft Azure, Microsoft Entra ID, Privileged Identity Management (PIM), Conditional Access, MFA and identity governance.
- **Security Monitoring & Threat Detection:** Microsoft Sentinel, Log Analytics, KQL, custom analytics rules, identity-based detection and investigation workflows.  
- **Threat Hunting:** Developing and tuning KQL hunting queries, investigating suspicious activity, using MITRE ATT&CK mappings and documenting findings.  
- **Security Automation:** Azure Logic Apps, scheduled hunting workflows, Sentinel watchlists, automated result classification, Excel reporting and analyst notifications. 
- **Microsoft 365 Security:** Microsoft Defender, security configuration, auditing and access controls.
- **Documentation & Reporting:** Technical project write-ups, query catalogues, threat-hunting registers, investigation procedures and continuous improvement.

## Projects / Labs

[Project 1: Microsoft Tenant Setup & Entra PIM Implementation](Project-1-Microsoft-Tenant-Entra-PIM.md)
Configured a Microsoft cloud environment and implemented Privileged Identity Management to explore secure administration and just-in-time privileged access.

[Project 2: Microsoft 365 Tenant Security](Project-2-Microsoft-365-Tenant-Security.md)
Explored Microsoft 365 security controls, including identity protection, MFA, Conditional Access and administrative security configurations.

[Project 3: Azure Log Analytics & KQL Exploration](Project-3-Azure-Log-Analytics-and-KQL-Exploration.md)
Connected security telemetry to Azure Log Analytics and developed KQL queries to investigate sign-in activity, audit events and other security-relevant data.

[Project 4: Sentinel Analytics Rule & Playbook](./Project-4-Sentinel-Analytics-Rule-Playbook.md)
Developed a Microsoft Sentinel detection rule and explored automated response workflows using Azure Logic Apps.

[Project 5: Impossible Travel Alert Lab](Project-5-Impossible-Travel-Alert-Lab.md)
Built an identity-focused detection scenario using Microsoft Sentinel and KQL to identify potentially suspicious sign-in patterns.

Project 6: Automated Threat Hunting & Reporting Lab
Recreated the core architecture of a threat-hunting automation programme I originally developed in my work environment.

The lab brings together Microsoft Sentinel, Azure Log Analytics, KQL, Sentinel watchlists, Azure Logic Apps and Excel Online to automate ten scheduled threat hunts, classify results, populate a structured review register and notify an analyst when the workflow completes.

I also developed an interactive website to demonstrate the architecture and show how the different components work together, including a simulated automation run and screenshots from my actual home-lab environment.

This repository is an ongoing record of that journey, including the projects that worked, the challenges I encountered and the improvements I made along the way.
